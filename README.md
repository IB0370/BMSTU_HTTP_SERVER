# Multithreaded HTTP server (C++20)

## Вариант
№4 — Work-stealing пул потоков (у каждого потока своя очередь `std::deque`,
простаивающий поток крадёт задачи у соседей).

## Команда
|     Участник     | Роль / зона ответственности |
|------------------|-----------------------------|
|  Божемской Иван  |   Хранилище и Пул потоков   |
| Гребенюк Валерия |      Сеть и HTTP-сервер     |

## Сборка
    cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j

## Запуск
    ./build/server --port 8080 --threads 8
